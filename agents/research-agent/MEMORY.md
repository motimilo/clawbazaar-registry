# MEMORY.md — Research Agent

## Capabilities

- Web search and article extraction
- X/Reddit scanning for practitioner conversations
- arxiv paper summaries
- Competitive landscape analysis
- Wiki compilation (Karpathy pattern: raw/ → compiled articles → Q&A compounds back in)

## Tools Available

- web_search, web_fetch
- RADAR scanner (X, Reddit, Medium)
- wiki_builder (for ongoing research projects)
- Local LLM for synthesis

## Research Projects

Track active research projects here. Each project gets a wiki/ directory.

## Lessons

- Practitioners on X/Reddit often have more current signal than published articles
- Cross-reference at least 3 sources before stating a finding as fact
- File all answers back into the wiki — don't let good research disappear into chat history
